## Slice 02 (2026-10-20)

Slice 02 integrates every VetBuddy input that was outside this repository into one validated reference corpus. It also records what was merged, what was dropped as a duplicate, and what still disagrees.

## 2. Redundancies removed

- **Crisis contacts:** one authored file instead of a second copy. The WV module's five-contact floor (and its "four copies by design") merges into `config/crisis_floor.yaml`. The standalone app's copy is generated, and a test fails on drift (`conflict.design.crisis_floor_copies`).
- **Jurisdiction parser:** `scripts/build_web.py` now uses `corpus.known_jurisdictions()` instead of its own regex over migration 0003.
- **Duplicate facts:** each fact is stored once and lists every source that reported it. Examples: Alabama unemployment 1.1% (both Alabama reports), the Hazlewood Act (Sentinel, finance report, landscape report), Colorado's retirement deduction (Sentinel and finance report), and the Alabama property exemption (finance report and Gen-3 client).
- **BAH tiers:** the Gen-3 client's four tiers are cells of the finance report's BAH sample table and are not carried separately.
- **Education programs:** 14 Education Navigator records plus 19 v2.0 records became 22 unique real programs. The synthetic demo grant and the five demonstration institutions were dropped.
- **Sentinel verification ledger:** folded into the rule-lead statuses and the conflicts table rather than kept as a second status list.
- **Governance rules:** each of R1–R22, T0-01..12 and the release gates appears once in `governance.json`. Required wording appears once, in `config/governance_language.yaml`.

## 3. Excluded on purpose

- **Individual staff names and personal emails** (state coordinators, facility staff). CLAUDE.md bars real PII in public datasets. Office lines, program URLs and role mailboxes are kept. The validator rejects `first.last@` mailboxes.
- **Pitch and market framing** in the Alabama landscape report. CLAUDE.md bars sales and investor work.
- **Childhelp (1-800-422-4453)** from the crisis floor. The WV runtime added it, but no primary-source check is recorded.
- **The retired crisis number 1-800-273-8255.** It is refused by the validator, a database CHECK and a test.
- **Approximate dates.** Events dated only to a year or month keep that precision; no day was invented.

## 5. How the rules are enforced

| Rule | Python (validator) | Database (0011) | Test |
|---|---|---|---|
| Every row names a registered source | yes | trigger `ref.assert_sources` | `test_unregistered_source*` |
| VERIFIED needs a named reviewer | yes | CHECK per table | `test_verified_*` |
| Leads and statistics are never VERIFIED | n/a | CHECK | `test_leads_and_statistics_can_never_be_verified` |
| Retired crisis number refused | yes | CHECK | `test_retired_crisis_number*` |
| Dedupe by organization and place, never phone | yes | unique index | `test_same_organization_and_place`, `test_natural_key_dedupe`, `test_phone_alone_is_not_a_duplicate` |
| Conflicts keep 2 or more readings | yes | CHECK | `test_single_reading_conflict*` |
| Money in integer cents; no interpolation | yes | `BIGINT` | `test_money_is_integer_cents`, `test_float_money` |
| Prohibited claim language (T0-01..03) | `claims_boundary.scan` | n/a | `ClaimsBoundary`, `test_prohibited_language` |
| App role reads, never writes | n/a | grants | `test_app_role_cannot_write` |
| No person or tenant columns in `ref` | n/a | migration guard | migration fails if violated |
| Status vocabulary identical in Python and SQL (RG-08) | `STATUSES` | domain CHECK | `test_status_vocabulary_matches_python` |
| Seed current and idempotent | `--check` | TRUNCATE + INSERT in one transaction | `test_build_check`, `test_seed_is_idempotent` |
